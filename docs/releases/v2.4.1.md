# ColumnPad v2.4.1

Release date: 2026-08-06

## Windows Build

This release publishes the current portable Windows x64 application build:

- `ColumnPadStudio.exe`
- Self-contained single-file executable; no .NET SDK or installer is required to run it.

## Included Improvements

- Optional update notification when a newer stable ColumnPad release is available.
- In-column picture placement with drag-and-drop insertion, proportional resizing, and text layering.
- More reliable column sizing, workspace recovery, and native layout handling.
- Workflow Builder templates, workflow JSON import/export, readable text and Markdown exports, and unsaved-change protection.
- Line numbers, proofing controls, themes, checklist helpers, and workspace-session support.

## Included Fixes

- Resolved blank picture panels and unstable picture resizing.
- Kept checklist state aligned through editing, paste, delete, replace, and undo actions.
- Preserved richer column state when moving between single-text and column modes.
- Removed stale picture and column event subscriptions after items are removed.
- Hardened invalid-layout, recovery, and workflow-data handling.

## Verification

- Release build completed with no warnings or errors.
- Passed 32 domain checks and 289 app smoke checks.
- Downloaded the published executable from GitHub, verified its checksum, and launched it successfully.

## Notes

- The executable is not code-signed yet, so Windows SmartScreen may warn on first launch.
- ColumnPad's optional update check requests only public GitHub release information; document content remains local.
