# ColumnPad v2.4.1

Release date: 2026-08-06

## Improved
- Expanded repository ignore rules for certificate bundles, strong-name keys, and common root-level secret files.

## Changed
- Replaced nonessential personal identifiers in public-facing documentation, licence attribution, and test fixture URLs with neutral project references.

## Documentation
- Updated the README with current release, installation, build, run, test, packaging, privacy, image-storage, and contribution guidance.
- Added a release-scope and privacy review to the release checklist.

## Verification
- Completed the Release build with no warnings or errors.
- Passed 32 domain checks and 289 app smoke checks.

## Release Artifact
- `ColumnPadStudio.exe`

## Known Notes
- The portable Windows executable is not code-signed, so Windows SmartScreen may warn on first launch.
- ColumnPad can make a brief best-effort request to the public GitHub releases endpoint on startup; document content is not sent.
- Imported images are copied to app-managed local storage, and native layouts keep references to those copies rather than embedding image data.
