# ColumnPad v2.2.4

Release date: 2026-07-09

## Updates
- Cleaned Workflow Builder file actions into one clearer area.
- Replaced separate visible workflow export buttons with one grouped `Export...` action.
- Kept workflow JSON as the proper import/export format for editable workflows.
- Kept readable workflow `.txt` and `.md` exports for sharing or reviewing workflows outside ColumnPad.
- Made Workflow Builder an independent window so it can be minimized separately from the main ColumnPad window.
- Fixed the Workflow Builder inspector so details align at the top of the right panel.
- Split workflow export formatting, workflow starter models, and workflow starter builder logic into clearer files.
- Updated the README so GitHub visitors are guided to download the Windows app first.

## Verification
- Release build passes.
- Domain tests pass.
- Smoke tests pass.
- Single-file Windows EXE publish was created.
