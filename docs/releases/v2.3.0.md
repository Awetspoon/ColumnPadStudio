# ColumnPad v2.3.0

Release date: 2026-07-15

## Updates
- Pictures now stay inside the column where they were inserted.
- Pictures can be dragged, resized proportionally, and placed in front of or behind text.
- Picture positions, sizes, layers, and source details reopen with native ColumnPad layouts.
- Fixed pictures sometimes appearing as blank white panels.
- Fixed jitter while resizing pictures.
- Improved default and saved column-width behavior across added, loaded, and resized columns.
- Kept checklist rows aligned with their text through common editing operations.
- Strengthened layout and recovery checks so damaged data cannot silently replace a valid workspace.
- Improved Workflow Builder import checks, change tracking, and unsaved-change prompts.
- Removed the old separate picture-tray implementation so there is one picture system to maintain.

## Verification
- Release build passes with no warnings or errors.
- 32 domain checks pass.
- 278 smoke checks pass.
- Formatting and repository consistency checks pass.
- Picture loading was visually checked in the published single-file Windows app.

## Release Artifact
- `ColumnPadStudio-v2.3.0-win-x64.exe`

## Known Notes
- The EXE is not code-signed, so Windows SmartScreen may warn on first launch.
- Plain `.txt` and `.md` files contain text only; use a native ColumnPad layout to preserve pictures and column layout.
